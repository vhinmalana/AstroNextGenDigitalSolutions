# Astro NextGen Digital Solutions

Redesigned to closely match the supplied light-blue homepage mockup.

## Run

```powershell
npm.cmd install
npm.cmd run dev
```

Open http://localhost:3000

For production testing:

```powershell
npm.cmd run build
npm.cmd start
```

Edit `data/siteData.ts` for company details, services, portfolio, partners and tech stack.

The contact form is a starter `mailto:` form; replace it with your preferred form/API service before production.
